# ⌨️ FinesKeys

Лёгкий и стильный оверлей нажатий клавиш и мыши для игр, спидранов и стримов на Windows. Написан на **AutoHotkey v1.1** с использованием **HTML/CSS**.

## ✨ Особенности
* **Прозрачный фон без рамки:** отображаются только кнопки и мышка, ничего лишнего поверх игры.
* **Свободное расположение:** перетаскивается в любую точку экрана зажатием ЛКМ за текст сверху.
* **Полный контроль:** отображение клавиш `W A S D`, `1–5`, `TAB`, `SHIFT`, `CTRL`, `SPACE`, `E`, `R`, `F`, а также ЛКМ, ПКМ, СКМ, боковых кнопок `X1/X2` и **живого счётчика CPS**.
* **Минимальная нагрузка:** практически не потребляет оперативную память и процессор.

## 🚀 Как запустить
1. Скачай и установи [AutoHotkey v1.1](https://autohotkey.com) (или скачай готовый `.exe`).
2. Запусти файл `FinesKeys.ahk`.
